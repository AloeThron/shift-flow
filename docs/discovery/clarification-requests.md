# คำขอความชัดเจน — Discovery Backlog (Q1–Q21)

> **สถานะ:** เปิด — ใช้ก่อนปิด Discovery Gate  
> **ที่มา:** สกัดจากตารางเวรจริง (OCR 8 เดือน + แผ่น OT) + ช่องว่างใน artifact inventory  
> **เอกสารคู่:** [shift-code-taxonomy.md](../domain/shift-code-taxonomy.md) · [domain-model.md](../domain/domain-model.md) · [artifact-inventory.md](./artifact-inventory.md)

เอกสารนี้เป็นรายการคำถามและสิ่งที่ต้องขอจากหน้างาน เพื่อยืนยัน taxonomy, constraint และ baseline — **ห้ามเดาคำตอบลงโมเดลโดเมน**

---

## วิธีใช้

1. นัดผู้ตอบตามคอลัมน์ “แหล่งที่น่าจะตอบได้”
2. บันทึกคำตอบในตารางนี้เท่านั้น (คอลัมน์คำตอบ / วันที่) — ห้ามคัดลอกตารางยาวไปเอกสารอื่น
3. เมื่อปิดข้อใด ให้เปลี่ยนสถานะเป็น `ปิด` และอัปเดต taxonomy / constraint / inventory ที่เกี่ยวข้อง
4. ชุดสั้นแนะนำก่อน: **Q1–Q4, Q8** (บล็อก ShiftCode + HC-003/004)
