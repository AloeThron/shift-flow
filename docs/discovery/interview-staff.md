# Interview Guide — เจ้าหน้าที่ห้องแล็บ / Lab Staff

> ระยะเวลา: 30–45 นาที (1:1) หรือ 45–60 นาที (focus group 4–6 คน)  
> กลุ่มเป้าหมาย: junior ≥ 1, middle ≥ 2, senior ≥ 1

---

## 0. ก่อนเริ่ม / Pre-session

### Consent script

> การสนทนานี้ใช้เพื่อออกแบบระบบดูตารางเวรและส่งคำขอลา/สลับเวร ไม่เก็บรายละเอียดอาการหรือข้อมูลผู้ป่วย  
> บันทึกจะถูกทำให้เป็นนิรนาม สามารถไม่ตอบคำถามใดก็ได้

- [ ] Consent ได้รับแล้ว
- [ ] วันที่: ___________
- [ ] รหัสกลุ่ม: `INT-STF-___` (ระดับ: Junior / Middle / Senior)
- [ ] รูปแบบ: 1:1 / Focus group

## 2. ประสบการณ์กับตารางปัจจุบัน (10 นาที)

1. รู้ตารางล่วงหน้ากี่วัน/สัปดาห์?
2. ดูตารางจากช่องทางใด (Excel, กระดาษ, Line, อื่น)?
3. ความชัดเจนของตาราง (1–5): ___
4. ความเป็นธรรมเวรดึก/วันหยุด (1–5): ___
5. มีกรณีที่รู้สึกว่า skill mix ไม่ปลอดภัยหรือไม่ ตัวอย่าง?

---

## 3. Availability, Leave และ Swap (15 นาที)

### 3.1 การแจ้งความพร้อม

| คำถาม                                       | บันทึก |
| ------------------------------------------- | ------ |
| แจ้งไม่ว่างอย่างไร ล่วงหน้ากี่วัน           |        |
| แยก hard unavailable กับ preference หรือไม่ |        |
| ระบบ/กระบวนการตอบกลับใช้เวลานานแค่ไหน       |        |

### 3.2 การลา

| คำถาม                                                        | บันทึก |
| ------------------------------------------------------------ | ------ |
| ประเภทลาที่ใช้ (เช่น ลาพักร้อน, ลากิจ, ลาฉุกเฉิน)            |        |
| ใครอนุมัติ                                                   |        |
| ควรเก็บเหตุผลระดับไหน (หมวดอย่างเดียว vs รายละเอียด)         |        |
| **ยืนยัน:** ไม่ควรเก็บรายละเอียดอาการ/ใบรับรองแพทย์ในระบบเวร | ☐ ตกลง |

### 3.3 Swap / รับเวรแทน

- เคย swap หรือรับแทนบ่อยแค่ไหน?
- ขั้นตอนปัจจุบัน (ใคร initiate, ใคร approve)?
- มีปัญหา double-booking หรือไม่?
- อยากให้ระบบตรวจอะไรก่อน commit swap?
