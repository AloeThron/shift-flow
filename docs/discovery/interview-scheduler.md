# Interview Guide — ผู้จัดเวร / Scheduler

> ระยะเวลา: 60–90 นาที  
> รูปแบบ: 1:1 หรือ 1:2 (scheduler + shadow observer)  
> ภาษา: ไทย (บันทึกคำศัพท์เทคนิคเป็นภาษาอังกฤษได้)

---

## 0. ก่อนเริ่ม / Pre-session

### Consent script (อ่านให้ฟัง)

> การสนทนานี้ใช้เพื่อออกแบบระบบจัดเวร Shift-Flow บันทึกจะถูกทำให้เป็นนิรนามก่อนนำเข้า repository เปิด source  
> ไม่มีการบันทึกชื่อผู้ป่วยหรือข้อมูลสุขภาพ สามารถข้ามคำถามใดก็ได้ และขอหยุดได้ตลอดเวลา

## 1. บทบนท Introduction (5 นาที)

1. บทบาทและประสบการณ์จัดเวร (กี่ปี, จัดกี่แผนก/จุดงาน)
2. จำนวนคนที่ต้องจัดต่อรอบตารางโดยประมาณ
3. ใช้เครื่องมืออะไรอยู่ (Excel, กระดาษ, ระบบ HR, Line)

---

## 2. Workflow ปัจจุบัน / Current Workflow (20 นาที)

### 2.1 วงจรการจัดตาราง

| คำถาม                                     | บันทึก |
| ---------------------------------------- | ---- |
| รอบตารางยาวเท่าไร (สัปดาห์/เดือน)?           |      |
| เริ่มเตรียมล่วงหน้ากี่วัน?                       |      |
| ขั้นตอนตั้งแต่เก็บ availability จนประกาศตาราง? |      |
| ใครอนุมัติขั้นสุดท้าย?                          |      |
| มี revision กี่ครั้งโดยเฉลี่ยต่อรอบ?             |      |

### 2.2 แหล่งข้อมูลที่ใช้

- รายชื่อพนักงานและ FTE มาจากไหน?
- competency/skill เก็บที่ไหน อัปเดตเมื่อไร?
- ปฏิทินวันหยุดและวัน substitute อยู่ที่ไหน?
- ใช้ข้อมูลรอบก่อนหรือไม่ (rest, fairness)?

## 4. Pain Points และ Edge Cases (15 นาที)

1. อะไรใช้เวลานานที่สุดในการจัดเวร?
2. กรณีที่แก้ยากที่สุด 3 อันดับแรก?
3. มี emergency/short-notice บ่อยแค่ไหน จัดการอย่างไร?
4. swap ระหว่างเจ้าหน้าที่ทำอย่างไร มีปัญหาอะไร?
5. เคย publish แล้วพบ violation ภายหลังหรือไม่ ตัวอย่าง?
6. ข้อมูลข้ามรอบตาราง (เวรก่อน/หลัง boundary) ตรวจอย่างไร?
